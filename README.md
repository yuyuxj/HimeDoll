# HimeDoll

HimeDoll.jp 日本向け WordPress / WooCommerce EC サイト。

## Version
v0.2.0 Theme Framework

## Included
- Custom WordPress theme
- Responsive header and footer
- Mobile navigation
- WooCommerce support
- Custom core plugin foundation
- Japanese homepage framework

## Installation
1. Copy `wp-content/themes/himedoll` to WordPress.
2. Copy `wp-content/plugins/himedoll-core` to WordPress.
3. Activate **HimeDoll** theme.
4. Activate **HimeDoll Core** plugin.
5. Install and activate WooCommerce.
