# HimeDoll v1.0.0 Production Ready

HimeDoll.jp 日本向け WordPress / WooCommerce 商城完整 Git 源码包。

## 已包含
- 商业首页
- 商品目录、品牌分类和筛选
- 商品详情、商品参数、视频字段
- 购物车和日本式结算页
- 会员中心、收藏和最近浏览
- SEO Meta、Open Graph、Product JSON-LD
- 18+ 年龄确认和 Cookie 提示
- HimeDoll 后台设置
- 法务页面自动生成
- 基础安全加固
- 基础性能优化
- Docker 本地开发环境
- GitHub Actions PHP 语法检查
- 安装和上线文档

## 使用方式

### 已有 WordPress
把以下目录复制到网站：
- `wp-content/themes/himedoll`
- `wp-content/plugins/himedoll-core`

然后启用：
1. WooCommerce
2. HimeDoll Core
3. HimeDoll Theme

### GitHub
将本压缩包内容完整覆盖到本地 Git 仓库根目录，再 Commit 和 Push。
