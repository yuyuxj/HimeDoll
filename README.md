# HimeDoll

HimeDoll.jp 日本向け WordPress / WooCommerce EC サイト。

## Version
v0.3.0 Commercial Homepage

## Main features
- Commercial Japanese homepage
- Responsive desktop/mobile header
- Search drawer
- Mobile navigation
- Trust and delivery sections
- Popular and new product sections
- Brand area
- Category cards
- Shopping flow
- FAQ preview
- WooCommerce support
- HimeDoll Core brand taxonomy

## Install
1. Copy `wp-content/themes/himedoll` into WordPress.
2. Copy `wp-content/plugins/himedoll-core` into WordPress.
3. Activate the **HimeDoll** theme.
4. Activate **HimeDoll Core**.
5. Install and activate WooCommerce.
6. Create a menu and assign it to `メインメニュー`.
7. Configure homepage text from Appearance → Customize → HimeDoll Homepage.
