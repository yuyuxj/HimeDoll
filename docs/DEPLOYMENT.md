# 上线部署

## 上线前
- 使用 staging 子域名测试
- 配置 HTTPS
- 配置每日数据库备份
- 配置文件备份
- 禁止在线编辑主题/插件
- 确认支付渠道允许当前商品类别
- 检查年龄提示、隐私政策和特定商取引法页面
- 测试下单、邮件、库存和退款流程

## Git 发布
1. 本地测试。
2. Commit。
3. Push 到 GitHub。
4. 服务器执行 `git pull` 或使用部署工具。
5. 清理缓存。
6. 重新保存固定链接。

## 生产环境不应提交
- wp-config.php
- uploads
- 缓存
- 数据库备份
- API Key
