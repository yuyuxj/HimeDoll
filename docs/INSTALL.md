# 安装说明

## 服务器建议
- PHP 8.2 或 8.3
- WordPress 6.x
- WooCommerce 最新稳定版
- MariaDB 10.6+
- HTTPS
- 256MB 以上 PHP memory_limit

## 安装步骤
1. 安装 WordPress。
2. 安装并启用 WooCommerce。
3. 上传 `wp-content/themes/himedoll`。
4. 上传 `wp-content/plugins/himedoll-core`。
5. 启用 HimeDoll Core。
6. 启用 HimeDoll 主题。
7. 进入后台 `HimeDoll → 初期设置`。
8. 点击创建必要页面。
9. 在“设置 → 固定链接”保存一次。
10. 设置菜单并指定为“メインメニュー”。

## 页面
安装器会创建：
- FAQ
- 配送
- 支付
- 保证与退换
- 公司概要
- 联系方式
- 隐私政策
- 利用条款
- 特定商取引法
- 收藏
